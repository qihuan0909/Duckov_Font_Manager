[h1]鸭科夫字体管理器 Duckov Font Manager[/h1]

[hr][/hr]

[h2]字体管理器 Font Manager[/h2]
把游戏里的字体换成你喜欢的任意字体，并附带字号、间距调整等功能。所有设置都在游戏内即时生效，不需要重启。

[h2]功能[/h2]
[list]
[*][b]全局替换字体[/b]：主菜单、设置、仓库、HUD、对话、伤害飘字等游戏文字都会替换，其他 Mod 的文字也可以一起替换。
[*][b]保留原有效果[/b]：标题的描边、阴影等效果会迁移到新字体上，不会变成“素字”。
[*][b]缺字自动补全[/b]：新字体里没有的字（比如英文字体没有中文），会自动用游戏原字体显示，不会出现方框；部分艺术字体把数字做成空白字形的情况也会自动处理，数字不会消失。
[*][b]字号调整[/b]：全局字号，以及界面文字、世界文字（伤害飘字等）、标题文字分别调整；可选“视觉字号归一化”，让新字体看起来和原字体一样大。
[*][b]即时热切换[/b]：在列表里点一下字体立刻生效；可以给不同游戏语言绑定不同字体，切换语言时自动换；往字体文件夹里放入新字体会自动出现在列表中。
[*][b]美术字体默认保留[/b]：时钟、倒计时等像素/数码管风格的字体默认不替换，保持原版美术风格；想全部替换可以勾选“强制覆盖美术字体”。
[*][b]游戏内设置面板[/b]：按 [b]F8[/b] 打开，或在游戏的“设置”界面点击“字体”标签。面板支持中文、English、日本語、한국어，默认跟随游戏语言。
[/list]

[h2]使用方法[/h2]
[olist]
[*]订阅本 Mod，在游戏主菜单的 [b]Mods[/b] 中勾选启用。
[*]把字体文件（.ttf / .otf / .ttc）放进：[b]游戏目录/ModConfigs/DuckovFontManager/Fonts/[/b]
（也可以在面板里点“打开字体目录”）
[*]按 [b]F8[/b] 打开面板，在左侧列表中点击字体即可。系统已安装的字体也会显示在列表里。
[/olist]

[h2]注意事项[/h2]
[list]
[*][b]本 Mod 不附带任何字体[/b]，请自行准备字体文件，并遵守字体本身的授权协议。
[*]首次加载较大的中文字体时可能有短暂卡顿，之后会在后台逐步预生成常用字。
[*]在 Mods 中取消勾选即可停用，所有文字会立即恢复原样，不影响存档。
[*]设置保存在 游戏目录/ModConfigs/DuckovFontManager/config.json，排除规则、字体分类等高级选项可在其中修改。
[/list]
