[h1]Duckov Font Manager (글꼴 관리자)[/h1]

[hr][/hr]

[h2]글꼴 관리자 Font Manager[/h2]
게임의 글꼴을 원하는 아무 글꼴로나 바꿀 수 있고, 글자 크기와 간격 조정 등의 기능도 함께 제공합니다. 모든 설정은 게임 안에서 즉시 적용되며 재시작할 필요가 없습니다.

[h2]기능[/h2]
[list]
[*][b]전체 글꼴 교체[/b]: 메인 메뉴, 설정, 창고, HUD, 대화, 피해량 표시 등 게임 안의 텍스트를 모두 교체합니다. 다른 모드의 텍스트도 함께 교체할 수 있습니다.
[*][b]원래 효과 유지[/b]: 제목의 외곽선, 그림자 등의 효과가 새 글꼴에도 그대로 적용되어 밋밋한 글자로 바뀌지 않습니다.
[*][b]없는 글자 자동 보완[/b]: 새 글꼴에 없는 글자(예: 영문 글꼴에 없는 한글)는 게임의 원래 글꼴로 표시되므로 네모(□)로 깨지지 않습니다. 숫자를 빈 글리프로 만들어 둔 일부 디자인 글꼴도 자동으로 처리되어 숫자가 사라지지 않습니다.
[*][b]글자 크기 조정[/b]: 전체 크기는 물론 UI 텍스트, 월드 텍스트(피해량 표시 등), 제목을 각각 조정할 수 있습니다. "시각적 크기 맞춤"을 켜면 새 글꼴이 원래 글꼴과 같은 크기로 보이도록 자동 조정됩니다.
[*][b]즉시 전환[/b]: 목록에서 글꼴을 클릭하면 바로 적용됩니다. 게임 언어마다 다른 글꼴을 지정할 수 있으며, 언어를 바꾸면 자동으로 전환됩니다. 글꼴 폴더에 새 글꼴을 넣으면 목록에 자동으로 나타납니다.
[*][b]디자인 글꼴은 기본적으로 유지[/b]: 시계, 카운트다운 등 픽셀/7세그먼트 스타일의 글꼴은 기본적으로 교체하지 않아 원래 아트 스타일을 유지합니다. 모두 교체하려면 "디자인 글꼴도 강제로 교체"를 체크하세요.
[*][b]게임 내 설정 창[/b]: [b]F8[/b] 키를 누르거나 게임의 "설정" 화면에서 "글꼴" 탭을 클릭하면 열립니다. 설정 창은 中文, English, 日本語, 한국어를 지원하며 기본적으로 게임 언어를 따릅니다.
[/list]

[h2]사용 방법[/h2]
[olist]
[*]이 모드를 구독한 뒤 게임 메인 메뉴의 [b]Mods[/b]에서 활성화합니다.
[*]글꼴 파일(.ttf / .otf / .ttc)을 다음 폴더에 넣습니다: [b]게임 폴더/ModConfigs/DuckovFontManager/Fonts/[/b]
(설정 창의 "글꼴 폴더 열기"로도 열 수 있습니다)
[*][b]F8[/b] 키로 설정 창을 열고 왼쪽 목록에서 글꼴을 클릭하면 됩니다. PC에 설치된 시스템 글꼴도 목록에 표시됩니다.
[/olist]

[h2]주의 사항[/h2]
[list]
[*][b]이 모드에는 글꼴이 포함되어 있지 않습니다.[/b] 글꼴 파일은 직접 준비하시고, 각 글꼴의 라이선스를 지켜 주세요.
[*]용량이 큰 한글·한자 글꼴을 처음 불러올 때 잠시 끊길 수 있습니다. 이후에는 자주 쓰는 글자를 백그라운드에서 조금씩 미리 생성합니다.
[*]Mods에서 체크를 해제하면 비활성화되며, 모든 텍스트가 즉시 원래대로 돌아옵니다. 세이브 데이터에는 영향을 주지 않습니다.
[*]설정은 게임 폴더/ModConfigs/DuckovFontManager/config.json에 저장되며, 제외 규칙이나 글꼴 분류 같은 고급 옵션은 이 파일에서 수정할 수 있습니다.
[/list]
